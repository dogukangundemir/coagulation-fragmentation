# Figures: invariants without the 1/2 flux bound (packet F5, part 2)

Generated by `scripts/figures/invariants_nobound.py` (CPU only). All numbers
below come from `data.csv` in this folder, which the script writes on every
run. Part 1 of this packet lives in `figures/mechanism/f5_invariants.png`
(README in `figures/mechanism/README.md`): it checks the trained CF-Full and
CF-NoFrag checkpoints per run against the same two tolerances. This part
isolates the 1/2 flux bound itself by comparing CF-Full with CF-NoBound
(`cf/models/cf.py`, `bound_flux=False`).

## f5_invariants_nobound.png

Packet figure: F5

**Caption.** Guardrail invariants of CF-Full vs CF-NoBound rolled out to
T = 64 on the first 64 mazes of the level-5 test split: the minimum monomer
concentration min c1 over all mazes, cells and channels per step (left,
symlog) and the relative mass drift max |M_t - M_0| / max(1, max M_0) of the
worst maze per step (right, symlog), against the pre-registered tolerances
-1e-7 and 1e-5. Three runs: CF-NoBound and CF-Full, both untrained (random
init, seed 0), and CF-Full trained 160 epochs at fixed T = 8 (seed 0).

**How to read.** Left: dashed blue = CF-Full untrained, dashed purple =
CF-NoBound untrained, solid blue = CF-Full trained; the black arrow marks
CF-NoBound's minimum -8.31e-2 at t = 1; the dashed vermillion line is the
positivity tolerance -1e-7 and the y axis is symlog (linear within
+/-1e-7, logarithmic beyond, because the trained run reports exact zeros).
Right: same three runs; t = 0 is the drift-free reference (drift 0 by
definition, not plotted); the dashed vermillion line is the mass-drift
tolerance 1e-5, and zero-valued steps (CF-NoBound at t = 1) are shown by the
symlog linear zone (linear within +/-1e-8). The two untrained models are
built under the same seed and have byte-identical initial weights
(`data.csv`, `untrained_init_identical = True`), so the difference comes from
the bound alone. Every curve is the worst case over the 64 mazes at that
step - nothing is averaged, so there are no error bars and no aggregated
bands to clip.

**Key takeaway.** Only the flux bound decides positivity: untrained
CF-NoBound breaks it on the very first step (min c1 = -8.31008e-2 at t = 1,
5.9 decades below the -1e-7 tolerance, recovered to +1.59e-1 by t = 2),
while untrained CF-Full stays at +1.49e-1 and trained CF-Full never falls
below 0 (exactly 0 at t = 1, final 5.69e-25). Mass conservation, in
contrast, is structural and holds for every run: the worst drift over all
runs and steps is 1.53612e-6 (trained CF-Full at t = 56), 6.5x below the
1e-5 tolerance; CF-NoBound's worst drift is 4.3028e-7 (t = 59), 23x below.

**Data source.** The 64 mazes are the first 64 of the level-5 test split
built by `scripts/run_week2.py load_data` (HF `selimaktas/maze-curriculum-
dataset`); the trained checkpoint is `week2_results/followups/
E1_CF-Full_seed0.pt` (160 epochs, T_train = 8, seed 0, run record in
`week2_results/followups/results.json`); the untrained models are
`run_week2.make_model("CF-NoBound")` / `("CF-Full")` seeded with seed 0;
tolerances as in `scripts/check_trained_invariants.py`. All invariants are
recomputed by the script from the rollout itself (`CFNet.step`, T = 64) and
written to `data.csv` (one row per run and step).

**Caveats.** Worst-case values over 64 mazes and 65 time points per run,
not means - no error bars because nothing is aggregated. Budgets: the
trained run is 160 epochs at fixed T = 8, seed 0 only (single seed, so
preliminary); the untrained runs are diagnostics with a single fixed seed
(seed 0), not evaluations. The rollout length T = 64 is 8x the training
depth T = 8, so the trained run is extrapolating beyond its training range;
mass drift at t = 64 (1.43e-6) is float32 accumulation, not model behaviour.
The trained CF-NoBound counterpart was not run: no 160-epoch CF-NoBound
checkpoint exists in `week2_results/` - "not run". Positivity failure of
untrained CF-NoBound at t = 1 comes from merge fluxes up to c1 * sigmoid
(unbounded, factor 1.0 instead of 1/2), so the exact value depends on the
seed; the sign and order of magnitude are the reproducible message.
